# پارسیان | سیستم حسابداری بوفه

سامانه مستقل مدیریت و حسابداری بوفه مدرسه پارسیان.

## امکانات نسخه پایه
- ثبت کالا و کنترل موجودی
- پرونده دانش‌آموز و مانده بدهی
- ثبت فروش نقدی، کارت‌خوان و نسیه
- ثبت تسویه بدهی دانش‌آموز
- گزارش فروش، صندوق و موجودی
- رابط فارسی و راست‌چین

## معماری
- Cloudflare Workers برای API و رابط وب
- Cloudflare D1 برای پایگاه داده مستقل
- قابل استفاده از مرورگر موبایل و کامپیوتر
- نسخه ویندوز در مرحله بعد با بسته‌بندی همین سامانه

## راه‌اندازی
تنظیمات در `wrangler.toml` قرار دارد. شناسه D1 باید در بخش `database_id` ثبت شود.
